# BB Overlay 1.12.0, the NavAIgate Console for everyone, 1 November 2026

So this is the release where you get the same Console I run my own businesses on every day, and it's one codebase, so there's nothing like a cut-down copy: my version is your version plus my own profile, and that's the only difference. When you open it the first time, a short Setup asks your name and what your Macs are called, and then you tick the features you want, and if you don't want to think about it you press Simple or Pro and you're done.

## What changed in both editions

- **The profile.** Everything personal, so your machines and what each one is for, your addresses, your folders, the work that has to stay on one machine, now lives in one file at `~/.config/navaigate-console/profile.json`, outside the plugins, so an update never touches it. Console, Fleet and Helper Desk all read the same file, and there's no token in it, ever: it only says which secret to read.
- **Setup and the tick boxes.** 122 features in nine groups, each with one plain line saying what it does. A box you can't use yet is greyed with the reason, for example "needs a second Mac" or "needs a public address", and a feature whose bb change isn't in your bb is hidden, so you never tick something that can't run.
- **Simple and Pro are now starting points.** Simple turns on the 38 features most people want on day one, and Pro turns on everything your setup can support, and after that you change any box you like.
- **Fleet** (0.3.0) works from your profile, so any names for your Macs, and if the profile is wrong it refuses to start work rather than guess which Mac it is. It needs two Macs and a brain, and it now creates its own tables, so a fresh self-hosted brain works with no migration.
- **Helper Desk** (0.2.0) and **the Markdown plugin** (1.2.0) come along as they are today, and the Helper Desk mascots can be switched off in Setup.
- **Prompt Stack** is new: tick boxes in a chat's side panel that choose which skill cards go in beside every prompt, and it includes Ray Amjad's create, maintain and audit prove-it skills under MIT. The Claude Code hook is opt-in and the installer prints the one command for it.
- **The brain kit** is in `extras/brain-selfhost-kit`, MIT, if you want your own brain on your own machine, and Setup takes its address.

## Community edition only

- Fresh installs get the Console with Setup, and `--edition simple` or `--edition pro` just picks the starting tick boxes.
- If you're on 1.11, running the installer again keeps your Simple or Pro exactly as it is, and `--console` moves you over, saving your old look first.
- The guided tour has a Console version, with the same "I've read this" on every step, pause, resume and replay.

## Private edition only

- My edition reads my profile on each Mac and behaves exactly as before. There are no private-only features: all 122 ship in both.
