# NavAIgate Console 1.14.0, a model on your own Mac in Claude Code, with your own skills and agents

So this one takes the Local chats from 1.13 and makes them something you can actually work in, because you open a new chat in bb, pick Local and a model on your Mac, and it runs in Claude Code with the skills and agents you tick.

## What's new

- **Local chats on Claude Code are on by default**, and they're not experimental any more. If you saved Setup on Console 1.13 with Local chats on the Claude Code harness unticked, as a fresh 1.13 install or a preset chosen there did, they stay off; tick them in Setup to use them.
- **A tick list for your skills and agents**, the Local loadout, with a bar that shows how much room is left before Claude Code starts to shorten the chat, and a **Most used** button that ticks the skills you use most in your Claude Code chats on this Mac, not counting Local chats.
- **A smaller and faster start**, because twelve Claude Code tools a Local chat doesn't need are left out, so on a clean, standard bb 0.49 a new chat starts at about 14,600 tokens where 1.13.0 started the same chat at about 25,800, and its first words came after about 72 seconds with the model not in memory.
- **Long answers arrive once**, because a long answer no longer gets sent again after five minutes, and on our own Mac one answer streamed for 26 minutes and arrived once.
- **Two models we test with**, Qwen 3.8 27B abliterated (Claude Code and opencode) and DeepSeek R1 14B abliterated (a chat model in opencode), and the steps to get them are under [Main models](https://github.com/skyremote/navaigate-console/blob/main/INSTALL.md#main-models) in the install guide.
- **The padlock** opens for a model whose name contains abliterated or uncensored, which means its maker says they removed its refusals, and the Console only labels it.

In 1.13.0 a project's own Claude settings could send a Local chat on Claude Code to another address, and 1.14.0 closes that, so it's worth updating. The cost is that a Local chat doesn't read a project's CLAUDE.md any more, but your ticked skills and agents still arrive.

## Limits

- We tested it on one 48 GB Apple silicon Mac, and smaller Macs and Windows aren't tested.
- A new chat takes about a minute or more to start, and then follow-ups come back in a few seconds.
- A few rare cases can still send a chat marked Local to a cloud account, and the Features guide inside the Console lists them.
- Settings an administrator manages for the Mac were not tested.

## Update

Run the same install line again, and it updates the Console where it is.

```sh
curl -fsSL https://raw.githubusercontent.com/skyremote/navaigate-console/main/install.sh | bash
```

Set up and the steps for the models: [INSTALL.md, Local models](https://github.com/skyremote/navaigate-console/blob/main/INSTALL.md#local-models-optional). A short page with pictures: [Local models](https://skyremote.github.io/navaigate-console/local-models.html).
