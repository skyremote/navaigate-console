# NavAIgate Console 1.14.1, Google Antigravity in bb, 24 November 2026

So on Tuesday's call I said I'd get Google's Neon model into bb and post what happened, and I did it that afternoon, and it turned out to be a small job, so this is a small release that gives you the same thing with one script.

## What changed

- **A script that adds Google Antigravity to bb.** bb can run any agent that speaks the Agent Client Protocol, and the Antigravity command line has that built in as `agy acp`, so `extras/antigravity/add-to-bb.sh` adds it to bb's Custom agents setting as Google Antigravity. I'd first added it by hand, and the test chat that answered from Neon first time was on that hand-made entry, and then I took the entry out and ran the script on the same Mac, and it put the same entry back and bb listed Gemini 4 Neon straight after with no restart.
- **It keeps the agents you already have.** Setting bb's Custom agents by hand replaces the whole list, so if you'd already added an agent there you'd lose it. The script reads what's there, adds its one entry and writes the lot back, and if it can't read your setting it stops and changes nothing. Run it with `--dry-run` first if you want to see the entry it would add, and it only shows that one entry and a count of the others, never what's inside them, because an entry can hold keys.
- **It doesn't install anything or sign you in.** You install the Antigravity command line yourself, and it uses the same Google sign-in as the Antigravity app, or `agy acp --login` if you've never signed in on that machine.
- **Nothing else moved.** The Console and the other plugins are the same as 1.14.0.

## What isn't there yet

The Console's own screens don't offer Antigravity. Home still asks Claude, Codex or Cursor and the Online and Local orbs don't list it, and the command line is the only way we've tested starting a chat on it. Putting it into those screens is a real change to the Console and it isn't in this release.

Which models you see depends on your Google plan, so I can't promise Neon on every account.

## If you already installed

There's nothing to update in bb. Get the script from this repository, install the Antigravity command line, and run `bash extras/antigravity/add-to-bb.sh`. The steps are in [INSTALL.md, Google Antigravity](../../INSTALL.md#google-antigravity-optional).

## Gates

The script has 22 tests of its own against a stand-in bb, covering an empty setting, a setting with other agents in it, an entry that's already there, an `agy` that has moved, a setting it can't read, a reply from bb that isn't ok, a missing command line, text in other languages on a machine set to an older character set, and a dry run that must not show another agent's keys, and all 22 pass. Installer tests 41 of 41. On one Apple silicon Mac with bb 0.49.0 and the Antigravity command line 1.5.16 the script ran against real bb three ways: a dry run that wrote nothing, an add into an empty setting, and a second run that changed nothing, and bb listed Gemini 4 Neon after the add. We haven't run it on Linux or Windows, we haven't run it on a real bb that already had other custom agents, and we haven't run it on a second machine.
