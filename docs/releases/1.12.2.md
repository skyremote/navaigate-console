# NavAIgate Console 1.12.2, clean installs work again, 2 November 2026

So this one matters if you installed 1.12.0 or 1.12.1 on a fresh machine and the Console said it failed, because that was us and not you, and Tom found it within an hour of installing, and we then ran a clean copy of BB 0.48.1 in a sealed test box and saw exactly the same thing.

## What changed

- **The Console installs on a clean machine.** BB installs a plugin with only its runtime packages, and two of our files reached for a part of the BB plugin toolkit that is only there on a developer machine, so the app half and then the server half failed to build. Both are fixed, and the Console now loads and runs on a plain BB 0.48.1 with nothing extra installed.
- **Your machine has its own name on the usage card.** If you run one machine and don't have Fleet, the usage card called it "This Mac" and then listed it again as "Unavailable". It now takes the name from your Console profile, the one you set in Setup, and it doesn't list the same machine twice.
- **The Daily peak chart stays a chart.** With only a few days of readings the bars stretched to fill the width and turned into big ovals, so each bar now stops at 28 pixels wide.
- **Smaller fixes that were already running on our own machines.** A visit to a mirror on another machine no longer resets the model you chose for that chat, and the allowance chip on Home shrinks instead of running under the Full access button.

## If you already installed

Run the same install line again, `curl -fsSL https://raw.githubusercontent.com/skyremote/navaigate-console/main/install.sh | bash`, and it picks up 1.12.2 where your Console is, and nothing is removed. If the first install stopped with "NavAIgate Console: install failed", this is the run that finishes it.
