# NavAIgate Console 1.12.5, your usage as spheres on Home, 10 November 2026

So this one is about usage, because I wanted to open Home and see straight away how much of each subscription I've got left and which one I'm burning through right now, and before this you had to read a table to get that.

## What changed

- **A sphere for each subscription.** Home has a new Usage card under the four tiles at the top, and every subscription you've got, so Claude, Codex and Cursor, is a glass sphere with liquid in it, and the liquid shows how much of the week is left (the month for Cursor), and if you'd rather see what you've used there's a Left and Used switch and it remembers which one you picked.
- **One subscription, one sphere.** If the same plan is read on two machines it's still one sphere, so you're not counting the same allowance twice.
- **Burn rate when you hover.** Hover over a sphere, or tap it on your phone, and the panel underneath gives you the burn rate, which is the percent an hour over the last 30 minutes, and it tells you which window runs out first at that rate and when. On the machine we tested it on that was 4.2% an hour on one plan, running out in about 12 hours, which was more than two days before the reset.
- **It burns when you're using it.** A subscription that's being used right now has flames round its sphere, and the flames get bigger as the burn rate goes up, so you can see which one you're using hardest without reading anything.
- **You can play with it.** Move the pointer across a sphere and the liquid tilts, and press it and it sloshes about, and honestly that bit is there because I like it.
- **It stops when nothing is moving.** A sphere that has settled stops drawing, they all pause when the tab is hidden, and if you've got Reduce motion on, each one is a single still picture.
- **You can switch it off.** It's in the feature list as "Usage spheres on Home", it's on by default in the Pro preset, and you can untick it like any other feature.

## If you already installed

Run the same install line again, `curl -fsSL https://raw.githubusercontent.com/skyremote/navaigate-console/main/install.sh | bash`, and it updates the Console where it is.
