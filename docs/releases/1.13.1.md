# NavAIgate Console 1.13.1, Fleet installs from Git on standard bb, 22 November 2026

So this is a small one, and it's about Fleet, because I put 1.13.0 on another Mac with standard bb 0.49.0 and Fleet wouldn't install from Git, it stopped with `Could not resolve "@get-bb/plugin-sdk"`, and I hadn't seen it before because I'd been running Fleet from a local folder where the SDK is already there.

## What changed

- **Fleet builds when it comes from Git.** bb installs a plugin from Git without its development packages, and Fleet needs bb's plugin SDK to build two of its three parts, the page and the part that runs on each machine, so both of those stopped for the same reason. The SDK is now one of Fleet's normal packages, at the same version as before, and that's the whole fix, so one line moved in `package.json` and the lock file follows it.
- **If your Pro install stopped on Fleet, this is why.** The installer with `--edition pro` installs Fleet with that same Git command, so if it told you an install failed and named Fleet, run it again now. We saw this on bb 0.49.0 and we haven't checked older versions of bb.
- **The second run doesn't pick the look for you.** The first run stopped before it chose the sidebar and the theme, and the second run sees the Console is already installed and leaves those alone, so after it finishes go to **Settings, Appearance** and choose **Navigation: Rail**, **Thread list: NavAIgate rail** and the NavAIgate theme, and pick Simple or Pro in Setup.
- **Nothing else moved.** The Console and the other plugins are the same as 1.13.0, and Fleet does the same things it did before.

## If you already installed

If Fleet is already running for you, there's nothing to do. If it isn't, run the install line again with the Pro preset, `curl -fsSL https://raw.githubusercontent.com/skyremote/navaigate-console/main/install.sh | bash -s -- --edition pro`, and it adds Fleet and updates the rest where it is.

## Gates

Fleet's type check passes and its suite ran 53 files and 750 tests, all passing, and one of them is new and fails if the SDK goes back under the development packages. We also put the 1.13.0 Fleet folder into an empty folder, installed it the way bb does for Git and ran `bb plugin build`, and it stopped with the same error, and the same steps with the fix built all three parts. Then Fleet installed from Git on bb 0.49.0 on one Mac and came up running. Installer tests 41 of 41, and the leak scan of the change is clean. We didn't run the full Pro install on a clean bb for this one.
