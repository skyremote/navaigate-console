# NavAIgate Console 1.12.3, the Quota retry tab tells you what is going on, 2 November 2026

So this is a small one, and it's about the Quota retry tab on a chat, because it showed a blank page whenever nothing was waiting, which is most of the time, and that looked broken even when BB's retry was doing its job.

## What changed

- **An empty tab now says so.** When no retry is waiting it reads "No retry is waiting for this chat", and it explains that if a chat stops at a usage limit or a temporary provider error, BB keeps your message and sends it again when it can.
- **You can see BB's last decision.** The tab shows the last time BB's retry checked this chat and what it decided, for example "no retry, because the error was not a usage limit or a temporary provider error", and every reason is in plain words.
- **A failed read doesn't pretend nothing is waiting.** If the tab can't read the retries it says that, and tries again in 15 seconds.
