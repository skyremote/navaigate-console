# NavAIgate Console 1.12.4, the Stash leaves your folders alone, 2 November 2026

So this is a small one, and it's about the Stash, because it was taking chats out of your folders after seven days the same as every other chat, and if you've filed a chat into a folder you've already decided where it lives, so the Stash shouldn't be moving it.

## What changed

- **The Stash only takes loose chats.** A chat you've filed into a folder, or one that works in a folder's directory, now stays in that folder however long it sits, and the chats outside your folders still move to the Stash after the number of days you set, which is seven by default.
- **Chats it already took go back once.** The first time the Console runs after the update, every stashed chat that sits in a folder goes back to that folder, and on the machine we tested it on that was 40 chats, back in their folders inside a minute.
- **Stashing by hand still works.** If you want a chat in a folder out of the way, you can still stash it yourself, and the Console leaves it in the Stash.
- **No folders, no change.** If you don't use Projects & Sections, or you've switched it off, the Stash works the way it always has, and if it's installed but doesn't answer, the Stash skips that round rather than guess where a chat lives, and it tries again ten minutes later.

## If you already installed

Run the same install line again, `curl -fsSL https://raw.githubusercontent.com/skyremote/navaigate-console/main/install.sh | bash`, and it updates the Console where it is.
