# NavAIgate Console 1.12.1, the new home of the project, 2 November 2026

So this one is a small release, and it's only about where you find us: the project used to be called BB Overlay, and from today the name and the address are both NavAIgate Console, which is `github.com/skyremote/navaigate-console`, because that's what you've actually been installing and it should say so.

## What changed

- **The install line.** Every install line in the README, INSTALL.md and the website now points at `skyremote/navaigate-console`, so the one to copy is `curl -fsSL https://raw.githubusercontent.com/skyremote/navaigate-console/main/install.sh | bash`, and `--dry-run` still shows you what it would do before it does anything.
- **If you already installed 1.11 or 1.12.0.** You don't need to do anything, because GitHub sends the old address to the new one, and the installer now knows both names, so running it again still sees your Console, Simple or Pro as ours and updates it where it is, and nothing is removed.
- **What stays the same.** The plugin ids, the folders under `~/.config/bb-overlay` and the guide's name in Settings are exactly as they were, so nothing on your machine moves, and there's no new feature in this release.

## Gates

Installer tests 41 of 41 pass, including five new ones: an install recorded under the old name is updated where it is (Console, and a 1.11 Pro), a copy from somewhere else is still left alone, a 1.11 Simple or Pro recorded under the old name can still move to the Console, our plugins are only installed from the new address, and a repository whose name only starts with ours is never mistaken for it.
