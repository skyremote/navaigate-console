# Profile

navmotion-skin reads nothing personal. There is no machine name, host, path, account or owner value to set.

Skins and the Markdown settings live in bb's own plugin settings and theme chooser, so they follow the user through bb and are not stored here.

`community.defaults.json` is empty on purpose. It exists so the release profile check can see that this plugin was looked at and found to need no profile values.
