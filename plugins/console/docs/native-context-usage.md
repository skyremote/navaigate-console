---
name: native-context
description: Save and restore native composer drafts and files, quote exact messages, discover native history and review scoped excerpts.
---

Use the native composer + menu → Drafts, context and review links, or Mod+Shift+S. Save a copy keeps the composer; Stash and clear clears only after durable save and only when no newer edit exists. Finish pending uploads first. Restore into an empty composer, or explicitly replace its current draft. The current project, environment and model selections remain selected; original destination details are shown on each saved copy. Saved file bytes are retained and re-uploaded to the selected project.

Context accepts a sidebar thread drag as a native reference. Quote and annotate preserves selected text, source message sequence and the user's comment separately. Browser and Agent Annotations remain the source for preview-element context.

History searches BB threads. On updated core it can discover one selected native Claude/Codex session on its original machine/workspace, preview its hash and import it into an idle native thread. Close the original CLI first. Import retains provider identity but starts no turn; account and provider resume still need live acceptance. The JSONL file reader is a separate read-only visible-text importer.

Device keeps local drafts. The updated native app also exposes Settings → Offline drafts, real file copies and on-device iPhone dictation where supported. Review and restore explicitly after reconnect. Never auto-send a device outbox. The normal voice service is not proof of local dictation.

Mod+Alt+G captures a chosen client window through the OS/browser display picker and attaches actual PNG bytes. It captures pixels, not accessibility text or another host's screen.

Reviews create expiring read-only links for the excerpts explicitly selected in the UI. They exclude files, tools and live-thread controls. Never share private material automatically. Test the public ingress route with synthetic text before telling someone a guest can reach it.

Mod+Shift+Enter starts a native task and keeps composing on updated core. Steer and Queue send-menu choices use BB's own dispatch modes. Do not substitute Stop for steering.
